# 状态与路由规范

## 状态归属

- 值只在单个组件使用时保留为局部状态。
- 多个相邻组件共享的短期状态提升到最近共同所有者。
- 跨页面、跨会话或需要独立订阅的状态才进入全局 Store。
- 服务器数据优先交给项目已有的数据请求或缓存层，不复制到全局 Store。
- 可从 props、路由或其他状态直接计算的值不再存一份。

## 更新

- 状态更新保持不可变语义，不直接修改框架管理的对象。
- 一个动作完成一项领域意图。异步动作明确开始、成功、失败和取消状态。
- 持久化状态声明版本、迁移和清理策略，不保存敏感信息。

## 路由

- 路由参数属于外部输入，使用前完成解析和校验。
- 可分享、可返回的筛选或选中状态写入 URL；临时界面状态留在组件内。
- 未知路由、无权限和资源不存在使用不同处理结果。
- 跳转保留项目的 base path、history 模式和查询参数约定。
