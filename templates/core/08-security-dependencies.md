# 安全与依赖规范

## 安全

- 不在源码、日志、截图或测试夹具中写入令牌、口令、私钥和真实个人数据。
- 浏览器端输入不可信。涉及 HTML、URL、文件、重定向和富文本时采用项目认可的校验或净化方案。
- 权限判断以服务端授权为准；前端权限控制只负责界面和导航体验。
- 外部链接使用安全协议。新窗口链接按项目策略设置 `noopener` 和 `noreferrer`。
- 不把敏感数据存入 localStorage、查询参数或客户端可读 Cookie。

## 依赖

- 使用项目声明的包管理器和版本策略。
- 添加依赖前检查现有依赖或平台 API能否满足需求，并说明新增依赖的用途、体积和维护风险。
- Agent 未获授权时不安装、升级、降级、删除或重建依赖。
- 不修改 `node_modules`，不提交包管理器缓存或生成的依赖内容。
- 安全升级与功能升级分开提交，便于审查和回滚。
