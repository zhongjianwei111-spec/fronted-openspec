# 数据与 API 规范

## 请求层

- 使用项目统一请求客户端，复用认证、错误转换、取消和日志策略。
- API 函数表达传输协议；页面或领域层负责把传输对象转换为界面模型。
- 查询参数和请求体按接口契约传递，不发送未定义字段或本地展示状态。
- 防止重复提交。具有副作用的重试需要接口幂等性支持。

## 数据语义

- 保留后端字段含义、单位、精度和枚举值。没有契约依据时不推断数据。
- 明确区分 `undefined`、`null`、空字符串、空数组、`0` 和 `false`。
- 格式化函数只改变展示形式，不修改原始业务值。
- 日期、时区和金额转换集中处理，并在接口边界写明假设。

## 错误与竞态

- 页面向用户显示可理解的失败结果；日志保留供诊断使用的上下文，不记录令牌和敏感数据。
- 搜索、筛选和路由切换产生并发请求时，取消旧请求或忽略过期响应。
- 乐观更新提供失败回滚，并避免用服务器旧响应覆盖用户的新操作。
