# 样式与无障碍规范

## 样式

- 使用项目已有的设计令牌、间距、颜色和响应式断点。
- 组件样式限制作用域，避免依赖 DOM 层级过深的选择器。
- 用布局系统处理尺寸变化，不以固定像素复制单一截图。
- 动画尊重 `prefers-reduced-motion`，并避免阻塞输入或页面滚动。

## 交互

- 交互控件使用正确的 HTML 语义；点击元素需要键盘访问时使用 `button` 或 `a`。
- 焦点顺序与视觉顺序一致。弹窗打开后管理焦点，关闭后将焦点还给触发元素。
- 表单控件具有可访问名称，校验信息与对应字段关联。
- 颜色不能作为唯一状态线索；文本和关键图形满足项目采用的对比度标准。
- 图片提供符合用途的替代文本，装饰图片使用空替代文本。

## 响应式

- 验证项目声明的最小与最大视口。
- 长文本、翻译文本、空列表、大列表和缩放到 200% 时不遮挡关键操作。
